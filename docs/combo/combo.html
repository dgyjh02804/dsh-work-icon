组合：ORBITAL + NEBULA + FRACTAL —— 4 版职责分工 设计稿 · 附最小尺寸叠加实测

版 A · 环主进度（弧长给准数）

唯一职责环＝主进度：弧长 + 运行体（唯一进度表达，最精确、最好横比）
云＝状态：正在干活才聚拢发亮，等待时散开暗淡（不表达进度）
分形＝完成态：完成瞬间外壳闭合，之后常驻"已闭合"形态
进度看哪里最外圈那道弧的缺口位置——缺口越小进度越大，一眼可辨
风险/崩点崩点：环与分形都是"闭合轮廓"，完成瞬间两个闭合动作会互相抢。
三档剖面省电＝数值变化才动、随后完全静止（云不漂、环不动、分形不转）｜标准＝云 0.2Hz 慢漂 + 当前层呼吸｜流畅＝环运行体绕行 + 云流动 + 层级展开动画（完成时换形态）

版 B · 云主进度（密度/半径）

唯一职责环＝外壳与刻度：满圈刻度表达"上限/预算"，永不表达进度
云＝主进度：云的紧凑度与核心亮度随进度增长
分形＝层级/深度：递归层数暗示子任务展开深度
进度看哪里中间那团云的松紧（但 46px 下最难辨，见实测）
风险/崩点崩点：**密度的可辨性最差**——46px 下"紧"与"松"只差几像素，一眼读不出数值。
三档剖面省电＝数值变化才动、随后完全静止（云不漂、环不动、分形不转）｜标准＝云 0.2Hz 慢漂 + 当前层呼吸｜流畅＝环运行体绕行 + 云流动 + 层级展开动画（完成时换形态）

版 C · 分形主进度（层级深度）

唯一职责环＝精确读数：弧长给准数（把"多少"交给环）
云＝背景常驻场：纯氛围，不承载任何数值
分形＝主进度：递归层级展开深度
进度看哪里递归三角展开了几层（离散 3~4 档）+ 环给准数
风险/崩点崩点：分形只有 3~4 档，**精度低**；必须靠环补数，于是"主进度"实际是两件东西。
三档剖面省电＝数值变化才动、随后完全静止（云不漂、环不动、分形不转）｜标准＝云 0.2Hz 慢漂 + 当前层呼吸｜流畅＝环运行体绕行 + 云流动 + 层级展开动画（完成时换形态）

版 D · 推荐：三者职责正交（无冲突）

唯一职责环＝主进度：弧长（唯一进度表达）
云＝活跃度/状态：跑着=聚拢发亮，等待=散开（唯一状态表达）
分形＝**结构骨架**：递归层级 = **子代理层级**（与你要的树同构，不表达进度）
进度看哪里最外圈弧长（唯一进度），另两个分别读"是否在干活"与"层级结构"
风险/崩点唯一代价：分形退到"结构"后，视觉上更安静——但它换来了"三个元素互不争抢"。
三档剖面省电＝数值变化才动、随后完全静止（云不漂、环不动、分形不转）｜标准＝云 0.2Hz 慢漂 + 当前层呼吸｜流畅＝环运行体绕行 + 云流动 + 层级展开动画（完成时换形态）
