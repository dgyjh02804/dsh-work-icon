④ MOIRE · 干涉环场 参考：“猫眼”调谐指示管 magic eye 的角度阴影 + 双光栅摩尔干涉

设计意图两层周期略差的同心细环叠在一起，进度就是两层周期的差 —— 你会看到一个“目（眼）”从中心长出来又收回去，而刻度几乎不动。
形状为什么特别
  • 它复现的是一种**光学现象**（摩尔纹 / 调谐管阴影角），而不是画出一个形状：图案由两组栅的周期差**涌现**出来，肉眼看到的粗条纹在 DOM 里并不存在。整个方案库里只有这一套是“看不见的条纹比画出来的线更重要”。
  • 进度编码是**连续涌现**的：条纹是滑着走的，不是一段一段点亮；中心那个暗“目”的直径本身就是进度读数，天然带“离收敛还差多少”的暗示。
  • 完成态的换形非常干净：栅全部收进圆心（scale→0.02）后淡出，留下一个实心亮盘 + 捕获环 —— “干涉收束成一个点”，物理上说得通，视觉上是一记明确收尾。
  • 所有细环都是静态几何，动的只有整组的 scale + opacity：零逐帧重绘。
不推荐组合把图标缩到 40px 以下、或在高 DPI 缩放链上，两组细环会互相抵消成一片灰噪声（摩尔纹天生对采样率极敏感）；另外它只表达单一标量，做不了分支 / 层级。
零件 / 可换性
零件是什么可换性
P1 双光栅静态栅 A（9 环 / 步长 9.2）+ 动态栅 B（15 环 / 步长 6.05），B 整组缩放可换：步长差决定“目”的数量（改 ±0.5 单位就能从 1 个目变 3 个目）；也可让 B 反向旋转做旋转摩尔纹
P2 核心中心亮盘 + 静态点可换：③ 的顶点点阵
P3 静态外环外圈 60 分格刻度环可换：② 的罗盘外环
P4 完成态栅塌缩 + 实心亮盘 + 捕获环可换：① 的“回正”语义（把栅锁到某一条完全对齐）
三态推进＝主元素随 p 连续变化；完成（换形态）＝同一元素换形态，不是贴装饰；静止呼吸＝核心 2.6s 呼吸（只改 transform/opacity）
三档省电＝数值变化才动、跳完完全静止（0 fps）｜标准＝10 fps 推进 + 慢呼吸｜流畅＝30 fps 全动
约束全页只动 transform / opacity（合成层）；无 backdrop-filter、无 filter:blur、无 box-shadow
