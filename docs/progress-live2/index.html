① LADDER姿态地平线航空姿态仪 attitude indicator（天/地 + 俯仰刻度梯 + 机翼 + 背向标）把“进度”从“一段弧有多长”换成“地平线沉到了哪里” —— 唯一会动的东西是被机翼挡在后面的那半颗球。
② AZIMUTH航道罗盘卡航空 HSI 水平状态指示器（罗盘卡旋转 + 航道偏差杆 + lubber line）整张罗盘卡在转（总进度），一根航道偏差杆横向滑向零位（当前任务离目标还差多远）—— 两个正交的读数共用一个圆心。
③ FAN粒迹扇形粒子物理事件显示：气泡室 / 火花室径迹图（顶点 + 发散径迹 + 末端点）把任务当成一次粒子事件：26 条径迹从同一点出发，各自交代自己的长度 —— 进度就是它们伸出去的比例。
④ MOIRE干涉环场“猫眼”调谐指示管 magic eye 的角度阴影 + 双光栅摩尔干涉两层周期略差的同心细环叠在一起，进度就是两层周期的差 —— 你会看到一个“目（眼）”从中心长出来又收回去，而刻度几乎不动。
