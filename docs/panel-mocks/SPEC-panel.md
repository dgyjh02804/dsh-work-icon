## 1. 几何（三套共用同一骨架）

| 项 | 值 | 说明 |
|---|---|---|
| 图标直径 | 140 px | 与现生产一致（`scale` 默认 140） |
| 原窗口 | 210 × 210 | 图标居中，四周各留 35 px（给辉光留位，SPEC §1 ratio=1.5） |
| **新窗口** | **210 × 341** | 高度 = 185（面板顶）+ 156（面板高） |
| 面板宽 | **210 px** | = 窗口宽；与图标**同一垂直中轴**（均为中心 x） |
| 面板顶偏移 | **185 px**（= 图标下缘 175 + **10**） | 展开方向：向下，窗口只增高、不移动图标 |
| 面板高 | 156 px（自适应，**上限 180**） | 内容行高体系见下 |
| 备选窄版 | 面板宽 140（= 图标直径） | 一行约少 3–4 个汉字，改动仅为 1 个参数 |

**内容行高体系（固定值，防抖动）**：状态 20 + 思考 34（2×17）+ 花费 18 + 任务 4×17=68 = **140**，加内边距 16 → **156**。
任务多于 4 条时**不再长高**，改为末行显示"还有 N 项"（避免窗口高度反复变化）。

**像素校验（渲染后实测）**：图标中心 x 与面板中心 x 偏差 **0.5 / 0 / 1 px**（A/B/C）；面板内文字行带 5–6 条、逐条分离无重叠（A:5 · B:6 · C:5，行带高度 10–12 px，行距均匀）。

## 2. 文字三态的实现

| 模式 | 窗口高 | 交互 |
|---|---|---|
| 不显示 | 210×210（不增高） | 与现在完全一致 |
| 悬停时显示 | 210×341（进入 hover 才增高） | 鼠标进入图标圆 → 展开；离开"图标 ∪ 面板"→ 收起 |
| 一直显示 | 210×341 | 常驻 |

- 三态由**右键菜单**切换，立即生效（沿用现有 `setting` → 宿主回发 `config` 的通路，键 `window.panel`，取值 `none|hover|always`）。
- 展开/收起用 **120 ms 淡入 + 高度直接切换**（不做逐帧 `setBounds` 动画——resize 逐帧会让 SVG 反复重排，且透明窗口 resize 有可见撕裂）。
- **hover 防抖**：鼠标进入图标即进入 hover；进入后设 **400 ms 宽限期**，期内即使鼠标移出图标也保持展开（否则鼠标下移去看面板时会立刻收起）。
- 面板**完全穿透**，所以鼠标停在面板上时点击/滚轮照常落到下层窗口 —— 这也是"宽限期"必须存在的原因（见 §3）。

## 3. 鼠标穿透区域划分（确认：做法技术上完全可行）

**结论：可行，而且沿用现有机制即可，不需要新原理。**

```
忽略鼠标（穿透） ⟺ 指针不在图标圆内（r = 70 = 140/2）
                    ↓
面板区域天然全部在圆外  →  面板永远穿透  ✓（纯展示，符合你的决定）
```

- 现有实现（`main.js`）：40 ms 轮询指针 → `insideIcon(px,py)` → `setIgnore(ignore)`；
  实测 exstyle 切换证据：`ignore=off → 0x08200008`（无 `WS_EX_TRANSPARENT`）↔ `ignore=on → 0x08280028`（有）；命中几何实测边界 `hitR=70`（0.99r 全部拦截、1.05r 全部穿透）。
- 面板区新增后**无需改动这段逻辑**：面板在圆外 → `ignore=true` → 全部穿透。
- 唯一要点：`setIgnoreMouseEvents(true, { forward: true })` 保持 `forward`，这样**鼠标在面板上方时仍能读到坐标**，hover 宽限期因此可判断"鼠标是否还在图标∪面板范围内"。
- 副作用（需接受）：面板覆盖的桌面区域无法用鼠标点到底下的东西——但你选的就是"完全穿透"，所以那个位置的点按**会照常落到下层窗口**，属于期望行为。

## 4. 三套方向的实现成本与风险

| 方向 | 实现成本 | 主要风险 | 兜底 |
|---|---|---|---|
| **A 深色 HUD 薄板** | **最低**：纯 CSS（半透明底 + 1 px 描边 + 行分割线），无滤镜、无模糊、无大阴影 | 极低。深底自带对比度，任何桌面/壁纸下都稳定可读 | — |
| **B 浅色便签** | 低：圆角 + `box-shadow` 大投影（透明窗口渲染阴影是 Chrome 正常能力） | ①浅色半透明叠在**浅色桌面上会"糊"**，文字对比度随桌面变化；②大面积浅色圆角块在透明窗口上更容易露出 1 px 暗边（此前踩过 `outer_frame_max_alpha` 的坑）；③投影在透明窗口边缘会被截断（窗口留白需 ≥ 投影模糊半径） | 把 alpha 从 .94 提到 .97，投影半径 ≤ 窗口留白 14 px |
| **C 无框全息** | 低：几乎没有底板，只有 1 px 极淡下划线 + 文字投影 | **最高**：没有底板 ⇒ 文字直接压在任意桌面内容上；花哨壁纸/浅色网页上会**读不清**（22% 暗雾 + 文字投影只能缓解）；无底文字在透明窗口上抗锯齿更易出现彩色描边 | 提供"仅悬停时显示"或加一层 40% 暗雾（那就退化成 A 的轻量版） |

**共同低风险项**：三套共用同一 HTML 骨架，**切换只是换一套 CSS 变量**（成本 ≈ 一个 `skin` 字段），所以"让用户挑"本身几乎零成本；也可以做成菜单里的第四项（外观：HUD / 便签 / 全息）。

**共同注意**：面板在"一直显示"模式下长期占用桌面空间，窗口变大 ⇒ 现有 `position` 记忆语义要明确：记录的是**图标窗口左上角**（面板向下展开不改变图标位置），无需迁移旧配置。

## 5. 跳动感（防抖动的具体技法）

1. **固定行高**：每行 `height` 与 `line-height` 全部写死（20 / 17 px），文本变化不改高度 ⇒ 面板不重排。
2. **单行截断**：`white-space:nowrap; overflow:hidden; text-overflow:ellipsis`（状态行、花费行、任务行）。
3. **多行截断**：思考行 `-webkit-line-clamp:2` + 固定 34 px。
4. **更新过渡**：只在**单行内容变化时**对该行做 `opacity 0→1` 120 ms 淡入；**不做整块面板的过渡**（整块过渡 = 闪）。
5. **数字**：`font-variant-numeric: tabular-nums`，避免花费/时间跳动时数字宽度抖动。
6. **禁止**：`flex-wrap:wrap`、`margin:0 auto`（流式与重排都抖）；面板高度不随内容逐帧变化。

## 6. 待宿主侧配合（不在本轮范围）

- `state` 载荷扩展：`cost {session, total}`、`tasks [{title, status}]`、`thought`（截断后的短文本，建议 ≤ 60 字）、`activity` 细化到工具名（`Bash`/`Edit`/`Read`）。
- 频率：思考/状态行走**节流**（建议 ≤ 2 次/秒，且只在文本真正变化时才发），否则面板会"抽搐"。
